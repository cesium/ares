# Ares

[![CI Test][ci-test-status]][ci-test-workflow]
[![CI Style][ci-style-status]][ci-style-workflow]

Ares is the platform for [BugsByte](https://bugsbyte.org/), CeSIUM's 48-hour hackathon. Built with [Elixir](https://elixir-lang.org/) and [Phoenix Framework](https://www.phoenixframework.org/), it is the place where participants get to know the event, its sponsors and partners, and sign up to compete.

It is also responsible for team formation, ticket payments through [Midas](https://github.com/cesium/midas), and an admin backoffice to manage the participating companies and the event settings.
